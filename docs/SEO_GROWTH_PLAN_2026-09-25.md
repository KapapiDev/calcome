# CalCome SEO Growth Plan v1 — 2026-09-25

## Why the strategy changes now

CalCome has completed the 100-calculator milestone and Search Console now provides enough evidence to move from inventory creation and foundational technical SEO into measured search growth.

The 2026-09-25 exports show:

- 19 clicks and 3,537 Web Search impressions over the last 3 months.
- Latest 7 days: 9 clicks / 271 impressions / 3.32% CTR / 22.38 average position.
- Prior 7 days: 3 clicks / 344 impressions / 0.87% CTR / 28.49 average position.
- 193 indexed pages and 55 not indexed on 2026-09-21.
- 219 Search Generative AI Feature impressions, with 154 in the latest 28 days and 61 in the prior 28 days.

The next bottleneck is therefore not calculator count. It is converting indexed inventory into stronger rankings, CTR, useful guide coverage, and repeatable search discovery.

## Operating thesis

1. Fix real indexability/canonical defects before adding content.
2. Prioritize pages already close to page-one/top-ten positions.
3. Improve snippets, answer framing, and internal links before creating large volumes of new content.
4. Create guides in coherent 5–10 article batches around measured demand.
5. Keep calculator pages calculator-first; use guides for informational/comparison/how-to intent.
6. Treat Generative AI exposure as an answerability/trust signal, not as a reason for search-engine-only copy.
7. Re-measure after 2–4 weeks and let data choose the next cluster.

## Deployment-budget rule

Content work follows `AUTOMATION.md`:

- local/workspace-first preflight
- one active task branch/PR
- 5–10 related guides per content batch rather than one PR per article
- ideally one validated push/Preview per batch
- exact-head CI before merge
- merged branch cleanup

The canonical execution sequence is maintained in `TASK_QUEUE.md` as SEO-021 through SEO-025.
